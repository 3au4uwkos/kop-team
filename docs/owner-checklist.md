Разработчик проверяет результат.

## 1. Безопасность репозитория — сделать первым

- [ ] **Отозвать GitHub-токен**, вшитый в URL `git remote` в локальном
      `.git/config`: GitHub → Settings → Developer settings →
      Personal access tokens → Revoke. Репозиторий публичный, токен в конфиге
      живёт на диске в открытом виде.
- [ ] Перевести remote на HTTPS без токена и подключить
      Git Credential Manager:
      ```
      git remote set-url origin https://github.com/<user>/<repo>.git
      ```
- [ ] Repository → Settings → Code security: включить **Secret scanning**
      и **Push protection**.
- [ ] Включить **Dependabot alerts** (следит за astro и @astrojs/sitemap).
- [ ] Settings → Branches → Add rule для `master`: запретить force-push.
