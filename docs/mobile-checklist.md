# Чек-лист мобильной проверки (этап 4, п. 7)

Автоматически проверено в сборке (см. отчёт по этапу 4):

- горизонтального скролла нет на 360×800, 390×844, 768×1024,
  844×390 и 1024×768 — на всех пяти страницах;
- все интерактивные элементы ≥ 48×48 px (WCAG требует 44, Lighthouse — 48;
  взят строгий порог);
- дровер: блокировка фонового скролла, закрытие по Esc и тапу вне,
  focus-trap, возврат фокуса на бургер, синхронный `aria-expanded`, `inert`
  на закрытом меню.

Остальное проверяется руками — **на реальных устройствах, а не только
в DevTools**. Ниже то, что нужно пройти владельцу.

## Устройства

## Что проверить

### Читаемость и раскладка
- [ ] Ни на одном экране нет горизонтального скролла (потяните страницу вбок).
- [ ] Крупные заголовки не обрезаются и не наезжают на фоновые слова-декорации.
- [ ] Текст в блоках «Подробнее» читается, строки не слипаются.
- [ ] В альбомной ориентации первый экран не «съезжает»: имя и регалии видны.
- [ ] На iPhone контент не уходит под «чёлку» и под нижнюю полосу жестов.
- [ ] Адресная строка при скролле не режет секции (проверка `svh`).

### Меню
- [ ] Бургер открывается и закрывается, крестик попадает под палец.
- [ ] При открытом меню фон под ним не скроллится.
- [ ] Тап мимо меню закрывает его.
- [ ] После перехода по пункту меню оно закрывается, а страница
      останавливается на нужной секции, не под шапкой.

### Свайпы и галереи
- [ ] Лента «Легенды ковра» листается пальцем, стрелки работают,
      счётчик меняется.
- [ ] Лента лагерных смен листается, активная точка растягивается в полоску.
- [ ] Галерея в секциях направлений листается, точки переключаются.
- [ ] Свайп по галерее не «утаскивает» за собой всю страницу.

### Направления
- [ ] Ниже ~560 px вместо круговой диаграммы — три вертикальные карточки.
- [ ] Первое касание карточки раскрывает её, второе — переводит к разделу.

### Скорость и плавность
- [ ] DevTools → Performance, запись прокрутки всей главной сверху вниз:
      кадров дольше 16,7 мс нет (провалов ниже 60 FPS не видно).
      В CSS движение построено только на transform/opacity, а фоновые
      слова используют scroll-driven animations без JS — но проверить
      это нужно на живом устройстве, автотестом такое не ловится.
- [ ] На 3G-throttling первый экран появляется без долгого белого поля.
- [ ] Прелоадер уходит быстро и не задерживает контент.
- [ ] Шрифты не «прыгают» после загрузки (подмена умеренная).

### Доступность движения
- [ ] При включённом «Уменьшении движения» (iOS: Настройки → Универсальный
      доступ → Движение; Android: Настройки → Спец. возможности) анимации
      выключены, а весь контент виден сразу.
